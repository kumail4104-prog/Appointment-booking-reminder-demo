# Appointment-booking-reminder-demo
A simple demo showing how businesses can confirm appointments and send helpful reminders to leads.

## What this project is about

This project shows how a business can confirm appointments, keep leads informed, and send reminders before a scheduled booking.

## How the workflow works

A lead chooses a suitable time, receives a confirmation message, and gets a reminder before the appointment. The workflow helps reduce missed bookings and keeps the process organized.

## Tools used

- n8n for workflow automation
- Calendar for appointment scheduling
- CRM for keeping booking details organized
- Confirmation messages for new appointments
- Reminder messages before the booking

## Project status

This is a portfolio demo built with sample data. It has not been connected to a live calendar or messaging service.
